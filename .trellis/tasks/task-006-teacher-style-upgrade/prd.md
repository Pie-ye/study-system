# PRD: Task 006 — Teacher 教學風格升級

## 摘要

調整 Teacher 的教學風格，從「提問式引導」改為「主動講解 + 開放式發想」，移除選擇題，以簡答與申論題為主，並在章節結束時明確告知學生今日進度完成。

## 現狀

目前的 Teacher 教學流程：
1. ~~啟發與診斷~~（已移除）
2. 核心教學（講解一個概念後出題）
3. 測驗與驗證（包含選擇題、問答題、實作題）
4. 重點整理

問題：
- 選擇題不適合啟發創意思考
- Teacher 有時仍被動等待學生提問
- 章節學完後沒有明確的「已完成，明天繼續」結尾
- 課程結束後使用者不知道進度到哪

## 目標

新的教學流程：

```
開課 → 直接講解核心概念（不問學生知不知道）
     → 出一題簡答 / 申論題（啟發思考）
     → 根據回答繼續深入或換下一個概念
     → 所有概念講完後總結
     → 明確告知：今日課程結束，明天繼續
```

---

## 功能需求

### F1: 主動講解模式

Teacher 不再問「你對這個了解多少？」或「你有什麼問題？」，而是直接開始講解。

第一句話應該是：
> 今天要學的是 [主題]。這個概念的核心是 [一句話總結]。讓我從 [第一個概念] 開始。

講解完一個概念後，直接出一題簡答或申論題，不問「你理解了嗎？」。

### F2: 移除選擇題

所有選擇題格式從 system prompt 中移除。改為：

```
【簡答題】
題目：[問題]
請用你自己的話解釋。

【申論題】
題目：[問題]
請寫下你的想法，越多越好。
```

### F3: 啟發創意思考

每堂課至少包含一題「發想題」：

```
【發想題】
題目：[開放式問題]
如果是你，你會怎麼設計？有沒有不同的做法？
```

發想題沒有標準答案，重點是讓使用者練習橫向思考。

### F4: 章節結束告知

當一個章節的所有核心概念都講解完後，Teacher 必須說：

> 📚 今天的課程到這裡告一段落。你學了 [概念1]、[概念2]、[概念3]。
> 明天繼續學習下一章。到時候見！

不再繼續問「還有什麼問題嗎？」或等待使用者回應。

### F5: 課程進度感知

Teacher 需要知道：
- 這是第幾課（從 `{{title}}` 中解析，如「Awesome Architecture 第01章」）
- 總共有多少課（從 `{{category}}` 和課程結構推斷）
- 課程結束時可以說「第 N 課完成，明天進入第 N+1 課」

## 技術方案

### server.py 變更

更新 `TEACHER_SYSTEM` 字串中的教學流程部分：

```python
## 教學流程

### 第一階段：核心教學（主動講解）
直接開始講解核心概念。第一句話就要進入主題。
- 每個概念講解完後出一題簡答或申論題
- 不要問「你理解了嗎？」——直接出題驗證
- 不要使用選擇題，一律用開放式問題

### 第二階段：發想與延伸
每堂課至少包含一題發想題：
【發想題】如果是你，你會怎麼設計？

### 第三階段：重點整理與進度告知
課程結束時明確告知：
「第 N 課完成，明天繼續第 N+1 課。」
```

### 格式約定

```python
## 格式約定

當你想出簡答題時：

題目：[問題]

當你想出申論題時：
【申論題】

當你想出發想題時：
【發想題】

```

### 關鍵限制

```python
## 重要限制
- 不要問「你對這個了解多少」或「你有什麼問題」
- 不要出選擇題（A/B/C/D 選項）
- 不要問「你理解了嗎？」——直接出題驗證
- 課程結束時必須明確告知進度，不要留懸念
```
