# PRD: Task 001 — MVP Daily Learning Portal

## 摘要

建立一個單一 HTML 頁面的每日學習入口網站，具備 Duolingo 風格的遊戲化機制，讓使用者每天打開頁面就能看到一個待學項目，完成或記錄不學的理由。

## 目標

- 解決「太多東西想學 → 不知道從哪開始 → 最後什麼都沒做」的學習癱瘓
- 提供最低摩擦的每日學習入口：打開 → 知道今天學什麼 → 學完打卡 / 寫理由跳過
- 用 streak + XP + 成就的遊戲化 loop 建立學習習慣

## 使用者流程

```
打開頁面
  ├─ 顯示今日任務（從佇列中挑選一個）
  │   ├─ 已完成學習 → 點「完成！」→ streak+1, XP+10 → 明天見
  │   └─ 沒學 → 選理由（太累/沒時間/沒動力/太難/其他...）
  │       └─ 送出 → 記錄跳過 → 明天見
  ├─ 查看進度（streak、XP、等級、成就）
  └─ 管理學習佇列（新增/編輯/刪除項目）
```

## 功能需求

### F1: 每日任務展示
- 打開頁面時，從學習佇列中隨機或輪詢選一個項目作為今日任務
- 顯示項目名稱、類別、預計時間
- 若今天已經完成或跳過，顯示「今天的進度已完成！」和明天倒數

### F2: 完成打卡
- 點「完成！」按鈕
- streak +1
- XP +10（+5 如果有寫筆記）
- 顯示慶祝動畫（簡單的 CSS 特效）

### F3: 跳過 + 理由
- 點「今天不學」→ 展開理由選擇
- 預設理由：太累、沒時間、沒動力、內容太難、今天想學別的、其他
- 選擇「其他」時可自訂文字
- 點送出後記錄跳過，顯示「沒關係，明天再來」

### F4: Streak 視覺
- 顯示當前連續天數（🔥 N 天）
- 顯示最佳連續天數
- 7/14/21/30⋯里程碑標記

### F5: XP + 等級
- 進度條顯示目前 XP / 升級所需 XP
- 等級名稱與圖示
- 升級時顯示慶祝

### F6: 成就徽章
- 解鎖條件見 spec
- 顯示已解鎖 / 未解鎖成就
- 每個成就一個小卡片

### F7: 學習佇列管理
- 顯示所有學習項目列表（類別分組）
- 新增項目：名稱、類別、預計時間、連結（選填）、備註（選填）
- 編輯 / 刪除項目
- 已完成項目移到「已完成」區

### F8: 深色模式
- 跟隨系統 prefers-color-scheme
- 也可手動切換

## 技術規格

- 單一檔案: `index.html`（內嵌 CSS + JS）
- 資料儲存: localStorage（key: `studySystem_*`）
- 依賴: 無（純 vanilla JS）
- 字型: 系統字型（`-apple-system, sans-serif`）
- 圖示: Unicode emoji（🚫 無外部圖示庫）
